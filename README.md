# Paketmanager Touch Application

Dieses Projekt stellt eine Touchscreen-Anwendung für einen Raspberry Pi 4 bereit.

## Voraussetzungen

* Python 3.10 oder neuer
* Abhängigkeiten aus `requirements.txt`
* Raspberry Pi OS mit aktiviertem Touchscreen und angeschlossenem Honeywell HF680 Scanner

## Start

```bash
python -m paketmanager.app
```
